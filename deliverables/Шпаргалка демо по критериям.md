# Шпаргалка: что показать по критериям

## Критерии заказчика

| Критерий | Что показать | Где |
|---|---|---|
| **К1.** 5–10 тестовых обращений | Пример заказчика: «Корпус Б, 312, принтер HP не печатает». Если спросят — «в наборе 10 обращений с эталоном» | Демо A |
| **К2.** ИИ верно заполняет поля и исполнителя | Поля с цитатами + топ-3 исполнителя с причинами | Демо A, B |
| **К3.** Диспетчер исправляет и подтверждает | Исправить одно поле → Enter → заявка назначена | Демо B |
| **К4.** Ручные действия с ИИ и без | 1,5 мин вручную → ≈ 0 с ИИ; 28 ч в месяц | Слайды 6–7 |
| **К5.** Стабильность и архитектура | Ядро, модули, порты; облако → локальная модель | Слайд 4 |

## Критерии экспертов

| Критерий | Баллы | Чем закрываем |
|---|---|---|
| Соответствие теме | 4 | Их боль и их пример с принтером 312 |
| Технологичность | 3 | Звонок голосом + авария без диспетчера |
| Работоспособность | 3 | Всё вживую, без скриншотов |
| Структура выступления | 3 | Слайды → демо → финальная фраза, ровно 5:00 |
| Демонстрация | 3 | Демо больше половины времени |
| Роли | 1 | «1 — человек, ∞ — ИИ-агенты» |

## Демо: 4 шага — «Цитаты → Enter → Голос → Вывод»

| Шаг | Время | Показать | Фраза |
|---|---|---|---|
| **A. Пишу** (заявитель) | 1:50–2:40 | Поля с цитатами; ИИ спрашивает «Сколько сотрудников?» | «Каждое поле — с цитатой» |
| **B. Проверяю** (диспетчер) | 2:40–3:15 | Правка поля; топ-3; **Enter** | «ИИ предлагает — человек решает» |
| **C. Звоню** (телефон готов заранее) | 3:15–4:15 | «Ответить» → голос ИИ → «принтер дымится» → авария, дежурные уведомлены | «Ни одного действия диспетчера» |
| **D. Итог** (руководитель) | 4:15–5:00 | Горячая точка «принтер в 312 — заменить» | **«Диспетчер больше не печатает — он принимает решения». Спасибо!** |

## Минимум, если всё пойдёт не так

1. Поля с цитатами (К2)
2. Правка + Enter (К3)
3. Авария → дежурные уведомлены
4. Финальная фраза на дашборде

Опаздываешь — пропусти правку поля в шаге B. Финал не режь никогда.

# Презентация защиты (кейс 9)

Спецификация: [../docs/specs/case9-presentation.md](../docs/specs/case9-presentation.md). Работает без интернета:
GSAP лежит в `vendor/`, шрифт Manrope — в `fonts/`. Палитра — с главного сайта (`packages/ui/src/tokens.css`),
фон светлых слайдов — один плоский цвет `#F5F6FB`, финал — графит `#14172B`.

## Как открыть

- Двойной клик по `index.html` (Chrome), затем **F5** или кнопка «старт показа» на кликере — полный экран.
- Или сервером: `npx serve presentation` / `python3 -m http.server -d presentation 4180`.
- Номер слайда — в адресе (`index.html#6`): после перезагрузки откроется тот же слайд.
- PDF: открыть `index.html?print` → печать в PDF (по слайду на страницу, все шаги раскрыты, фон включить).

## Клавиши (кликер Logitech R400 = клавиатура)

| Клавиша | Действие |
|---|---|
| `PageDown` «›», `→`, `↓`, `Space`, `Enter` | следующий шаг / слайд. На демо-слайде открывается вкладка `http://localhost:5173` (один раз) и показ переходит дальше |
| `PageUp` «‹», `←`, `↑`, `Backspace` | предыдущий шаг / слайд |
| `F5` / `Shift+F5` «старт показа» | полный экран вкл/выкл (страница **не** перезагружается) |
| `.` или `B` «чёрный экран» | затемнить / вернуть |
| `F` | полный экран вкл/выкл |
| `Home` / `End` | первый / последний слайд |
| `V` на демо-слайде | запасное видео `media/demo.mp4` (`V`, `Esc` или «‹» — закрыть) |

Клавиши читаются по `key`, а при его отсутствии — по `keyCode` (Chrome, Safari, Firefox, Edge; клавиши «Next/Prior» старых браузеров тоже). Курсор прячется через 2 с.
Если браузер блокирует всплывающие окна, демо-слайд остаётся на месте и показывает подсказку: разрешите окна для этой страницы и нажмите снова.

## Где менять цифры

Только в объекте `DATA` в начале [`presentation.js`](presentation.js). У каждой цифры есть `value` и
`source`; `value: null` — на слайде «❓ замер», пунктирная рамка. Источники: слайды 5 — `reports/quality.md`
и `testset/cases`; 6–8 — `reports/measure.md`; 9 — `reports/sonarqube-summary.md`. Демо-цифры
`/measure?demo=1` не брать. Число тестов (`tests`) — из вывода свежего `pnpm check`; пока `null`,
строка со счётчиком тестов скрыта (`data-if`). Овал и зачёркивание скрываются, пока нет цифры (`data-if`).

## Видео

- `media/demo.mp4` — запасное видео демо (клавиша `V` на последнем слайде). Нет файла — подпись «видео не найдено».
- `media/manual.mp4` — ручной режим для слайда 7. Положить файл и указать `SHOW.manualVideo = 'media/manual.mp4'`
  в `presentation.js`. Пока `null` — блока с видео на слайде нет вовсе.

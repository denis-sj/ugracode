# Правила: секреты и данные

Статус: active
Дата: 2026-11-14
Связано: [git-and-deploy.md](git-and-deploy.md)

Меняются только с «ок» владельца.

1. Никогда не коммитить секреты: API-ключи LLM, токены, пароли, содержимое `.env`, строки подключения с паролями. В репозитории только `.env.example` с пустыми значениями.
2. В документах про секреты писать только «задан / не задан».
3. Демо-данные синтетические (вымышленные люди, телефоны, адреса). Реальные персональные данные не загружать: многие заказчики требуют соблюдать 152-ФЗ.
4. Контакты менторов из кейсов хранятся только в приватном репозитории, наружу (в публичные демо, презентации) не выносятся.
5. Перед защитой проверить, что в демо не видно ключей (DevTools, логи, экран настроек).

# Правила: git и деплой

Статус: active
Дата: 2026-11-14
Связано: [testing.md](testing.md), [../knowledge/environments.md](../knowledge/environments.md)

Меняются только с «ок» владельца.

1. Репозиторий: `https://github.com/denis-sj/ugracode` (приватный). Основная ветка — `main`.
2. В `main` напрямую не пушить. Вся работа идёт в ветках, влитие через PR. Мержит владелец.
3. Имена веток: `feature/<кратко>`, `fix/<кратко>`, `docs/<кратко>`.
4. Коммиты маленькие и осмысленные, сообщение на русском или английском в повелительном наклонении («Добавить классификатор заявок»).
5. Перед PR: тесты зелёные, проверка ссылок документации зелёная, чек-лист из `.github/pull_request_template.md` пройден.
6. Не делать `git push --force` в `main` и не переписывать историю чужих веток.
7. Хакатон длится ~24 часа: за **2 часа до дедлайна** — заморозка фич. Только багфиксы, демо-данные и презентация.
8. В последний час `main` должен быть в рабочем, задеплоенном состоянии, а ссылка на репозиторий и презентация загружены на платформу.
9. Деплой: ❓ уточнить (хостинг демо ещё не выбран, см. [../knowledge/environments.md](../knowledge/environments.md)).

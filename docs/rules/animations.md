# Анимации интерфейса — как делать (обязательно для кодера)

Статус: active
Дата: 2026-11-14
Связано: [../../AGENTS.md](../../AGENTS.md), [../specs/case9-ui-design.md](../specs/case9-ui-design.md#23-анимации), [code-quality.md](code-quality.md), [testing.md](testing.md), [../map/recipes.md](../map/recipes.md#анимировать-экран)

Анимации — часть «вау» на защите, но они не должны мешать работе и ломать демо. Весь код анимаций
живёт в одном файле: [`packages/ui/src/motion.ts`](../../packages/ui/src/motion.ts). Модули его
только **используют**: свой GSAP/Motion в модулях не импортировать.

## 1. Что уже работает само (ничего делать не надо)

`useBlockMotion` подключён один раз в `apps/web/src/App.tsx` на весь контент. Он:

- при открытии **любой** страницы показывает блоки каскадом снизу (0,55 с, шаг 0,06 с);
- ловит блоки, добавленные позже (данные догрузились, новое сообщение чата), и показывает их по одному;
- вложенные блоки едут вместе с родителем, а если родитель давно на экране — сами;
- через ~1 с после конца анимации снимает прозрачность, даже если вкладка в фоне и кадры стоят
  (иначе блок мог остаться невидимым на защите);
- при `prefers-reduced-motion` ничего не анимирует.

Какие узлы считаются блоками (`BLOCK_SELECTOR` в `motion.ts`):

1. всё с атрибутом `data-reveal`;
2. компоненты `@ugra/ui`: `Card`, `StatTile`, `Sticker`, `StepBlock`, `InsightBlock`, `EmptyState`;
3. запасной путь — прямые дети корня страницы (`.shell-main > * > *`) и экрана входа.

Сами анимируются и компоненты: `ConfidenceBar` (шкала наполняется), `ProgressScale` (сегменты
зажигаются по очереди), `StepBlock` (раскрытие по высоте), `StatTile` (цифра набегает),
`Modal` (пружина; у `tone="ok"` — конфетти).

## 2. Новый экран — чек-лист

1. Корень страницы — один элемент (`<div className="xx-page">`), внутри — секции.
2. Поверхности — через `Card` из `@ugra/ui`, а не свой `div` со стеклом: тогда анимация уже есть.
3. Свой блок, который должен появляться отдельно, — пометить `data-reveal`:
   ```tsx
   <div className="rd-chart" data-reveal>…</div>
   ```
4. Не анимировать: шапку таблицы, фон, декоративную сетку, тосты, окна — они уже исключены
   (`aria-hidden="true"`, `tr`/`thead`/`tbody`, `.ugra-modal`, `position: fixed`). Своё исключение —
   `data-motion="off"` (действует на узел и всё внутри).
5. Списки, где строки добавляются/удаляются/переставляются (очередь, уведомления, задачи), —
   повесить `useListMotion` на **родителя строк**:
   ```tsx
   const listRef = useRef<HTMLTableSectionElement | null>(null);
   useListMotion(listRef, rows.length > 0); // включать, когда родитель уже в DOM
   <tbody ref={listRef}>{rows.map(…)}</tbody>
   ```
   Образец: `modules/dispatcher-review/web/QueuePage.tsx`.
6. Важное событие (заявка назначена, авария объявлена) — `Modal` c `tone="ok"` даёт пружину и
   конфетти сам. Вне окна: `celebrate(element)` — **не чаще одного раза на действие пользователя**.
7. Проверить в браузере: открыть экран, переключить вкладку туда-обратно — блоки въезжают, ничего
   не мигает и не остаётся полупрозрачным. Проверить с включённым «Уменьшить движение» в системе.

## 3. Какая библиотека для чего

| Задача | Чем | Функция из `motion.ts` |
|---|---|---|
| Появление блоков, каскады, шкалы, раскрытие | **GSAP** | `useBlockMotion`, `revealBlocks`, `fillBar`, `popSegments`, `expandBody` |
| Строки списка появляются/исчезают/переставляются | **@formkit/auto-animate** | `useListMotion` |
| Пружинные окна и панели | **Motion** (`motion`) | `springIn` |
| Праздник на важном действии | **canvas-confetti** | `celebrate` |
| Простые постоянные эффекты (пульс аварии, перелив «думаю») | **CSS** `@keyframes` в `packages/ui/src/styles.css` | классы `ugra-pulse`, `ugra-shimmer` … |

Нужна новая анимация → добавить функцию в `motion.ts` (с проверкой `prefersReducedMotion()`),
экспорт уже идёт через `index.ts`, тест — в `packages/ui/tests/motion.test.ts`.

## 4. Запрещено

- Импортировать `gsap`, `motion`, `@formkit/auto-animate`, `canvas-confetti` прямо в модулях — только через `@ugra/ui`.
- Анимировать `width`, `height`, `top`, `left`, `box-shadow`, `backdrop-filter` в цикле — только
  `opacity` и `transform` (стекло с `backdrop-filter` тормозит). Исключение — `expandBody` (один раз).
- Ставить на один узел и CSS-анимацию появления (`ugra-rise`, `animation: …`), и GSAP — конфликт,
  блок дёргается. Выбрать одно: узлы с `.ugra-rise` GSAP пропускает.
- Бесконечные анимации, кроме статуса аварии и индикатора «ИИ думает».
- Длиннее 0,9 с на появление и задержку каскада больше 0,6 с — жюри ждёт, демо 5 минут.
- Анимации без проверки `prefers-reduced-motion`.
- Конфетти и «праздники» на каждый клик, на ошибках и на экране аварии.

## 5. Тесты

Тесты анимаций идут в окружении DOM: первая строка файла `// @vitest-environment happy-dom`.
Проверять логику (что анимируется, что пропускается, reduced motion, страховка), а не кадры.
Образец: [`packages/ui/tests/motion.test.ts`](../../packages/ui/tests/motion.test.ts).

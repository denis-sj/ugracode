## Что где лежит

| Папка | Что там |
|---|---|
| `hackathon/` | Всё о мероприятии: положение, критерии, кейсы, выбор кейса, стратегия победы. **Источник правды о требованиях.** |
| `rules/` | Обязательные правила. Меняются только с «ок» владельца. |
| `knowledge/` | Факты: люди, проект, окружения и стек. |
| `map/` | Карта кода для кодера: слои, точки входа, рецепты, фичи. |
| `ideas/` | Идеи, по файлу на идею. Статусы: 💡 новая / 🔄 в работе / ✅ принята / ❌ отклонена. |
| `specs/` | Утверждённые спецификации. |
| `plans/` | Планы реализации, у выполненных шагов SHA коммита. |
| `tasks/` | Очередь задач для агентов. |
| `history/` | Журнал закрытых задач по месяцам. |
| `sessions/` | Записи обсуждений с владельцем. |

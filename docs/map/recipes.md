# Рецепты

Статус: draft

Связано: [README.md](README.md)

Пошаговые инструкции для частых изменений, каждая со ссылкой на реальный файл-образец.

## Добавить документ в docs/

1. Создать файл с блоком-заголовком (Статус, Дата, Связано).
2. Если файл лежит в `docs/rules/`, `docs/map/`, `docs/knowledge/` или `docs/hackathon/`, добавить его в дерево в `AGENTS.md`.
3. Запустить `python3 -m unittest discover -s tests`.

Образец: `docs/hackathon/criteria.md`.

## Анимировать экран

1. Поверхности собрать из `Card` (`@ugra/ui`) — появление уже работает через `useBlockMotion` в `apps/web/src/App.tsx`.
2. Свой отдельный блок — атрибут `data-reveal`; исключить — `data-motion="off"`.
3. Список с добавлением/удалением строк — `useListMotion(ref, enabled)` на родителя строк.
4. Проверить в браузере и с «Уменьшить движение».

Подробно и что запрещено — [правила анимаций](../rules/animations.md). Образец: `modules/dispatcher-review/web/QueuePage.tsx`.

## Сделать экран читаемым в тёмной теме

1. Цвета брать только из `packages/ui/src/tokens.css`; парные значения уже есть в `html[data-theme="dark"]`.
2. Новый цвет заводить сразу двумя значениями: в `:root` и в тёмном блоке (иначе в тёмной теме будет светлое пятно).
3. Не использовать `#fff`, `#0F1222` и `rgba(...)` в CSS экрана — только переменные; для текста на фиолетовой заливке — `--color-on-accent`, на графитовой кнопке — `--color-graphite-contrast`.
4. Проверить: переключатель в шапке (или плавающий на входе), перезагрузка в тёмной теме без вспышки светлой, контраст основного текста ≥ 4,5:1.

Подробно — [ui-shell.md](features/ui-shell.md#тёмная-тема-24). Образец: `packages/ui/src/tokens.css`.

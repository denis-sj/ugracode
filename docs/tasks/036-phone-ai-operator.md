Решения владельца (2026-11-14) — заменяют раздел «Позже: звонок на номер» в задаче 019:

| Вопрос | Решение |
|---|---|
| Формат | **Живой ИИ-оператор**: звонишь на номер → ИИ отвечает голосом, задаёт 1–2 уточнения, кладёт трубку → заявка уже в очереди у диспетчера |
| Телефония | **Voximplant** (номер РФ, сценарий VoxEngine на JS) |
| Речь ↔ текст | **Встроенные у Voximplant** распознавание и синтез (Яндекс SpeechKit внутри). Звук к нам не идёт — только текст. Polza для речи не нужна (там 403) |
| LLM | `deepseek/deepseek-v4.1-flash-1017` через Polza — та же модель и тот же агентный пайплайн, что у разбора |

## Архитектура

```
Телефон ──► Voximplant (номер РФ)
              VoxEngine-сценарий: приветствие (TTS) → ASR ru-RU → фраза
                 │  HTTPS POST /api/voice/turn  {callId, from, text}
                 ▼
            наш API (modules/voice-call/server)
              диалоговый шаг LLM → {say, done, emergency}
                 │  ответ ≤ 6 с, иначе запасная фраза
              VoxEngine: TTS(say) → снова ASR … до done или 3 реплик / 90 с
                 │  HTTPS POST /api/voice/end  {callId, from, transcript[]}
                 ▼
            обращение source = 'call' → тот же пайплайн разбора → заявка в очереди
            экран диспетчера «Входящий звонок»: реплики появляются вживую
```

## Что сделать

1. **Сценарий VoxEngine** — `modules/voice-call/voximplant/scenario.js` (в репозитории, владелец вставляет его в кабинет).
   Входящий → приветствие + «звонок записывается и обрабатывается ИИ» → ASR (`ru-RU`, Яндекс) → `Net.httpRequestAsync` на `/api/voice/turn`
   → TTS ответа (голос Яндекса) → цикл. Пока ждём ответ сервера — короткая фраза-заполнитель («Секунду, записываю»).
   Таймаут сервера 6 с → запасной вопрос («Уточните, пожалуйста, кабинет и как с вами связаться»). Лимит: 3 реплики или 90 с.
   В конце — `/api/voice/end`, прощание с номером заявки, если сервер его вернул.
2. **API** (`modules/voice-call/server/`): `POST /api/voice/turn`, `POST /api/voice/end`, `GET /api/voice/calls/:id` (для экрана).
   Защита — заголовок `X-Voice-Secret` = `VOXIMPLANT_WEBHOOK_SECRET` из `.env`; без него 401. Входы через zod.
   Состояние звонков — в БД (таблица модуля) или память процесса с TTL; на `end` — обращение с `source: 'call'`, номер звонящего в контакт заявителя.
3. **Диалоговый шаг LLM**: короткий промпт, `json_schema` `{say: string ≤ 200 символов, done: boolean, emergency: boolean}`, малый `max_tokens`.
   Политика: максимум 2 уточнения (что сломалось, где/кабинет); признаки аварии (дым, искрит, запах гари, нет связи у всего этажа) →
   сразу `emergency: true`, фраза «Передаю дежурному», дальше — существующий модуль `emergency`. Говорить коротко, без markdown.
   Замерить задержку; если > 6 с стабильно — сообщить владельцу.
4. **Экран диспетчера «Входящий звонок»** (`modules/voice-call/web/`): карточка активного звонка — номер, таймер, реплики «Заявитель / ИИ»
   появляются вживую (опрос 1 с или SSE, если 035 уже добавил поток), после `end` — ссылка на созданную заявку. Анимации — по [правилам](../rules/animations.md).
5. **Симулятор без телефона**: `pnpm voice:sim` — скрипт гоняет `turn`/`end` с текстами из `testset/` (для тестов и как запасной путь демо).
6. **Тесты**: успех; нет/неверный секрет; LLM упала или таймаут → запасная фраза; авария → `emergency`; лимит реплик; модуль выключен флагом.
7. Документы: `modules/voice-call/README.md` (настройка Voximplant по шагам для владельца), карта фичи `docs/map/features/voice-call.md`,
   `.env.example` (`VOXIMPLANT_WEBHOOK_SECRET`, `PUBLIC_API_URL`), шаг в `docs/hackathon/demo-script.md`, ограничения в `docs/knowledge/limitations.md`.

Папки: `modules/voice-call/`, `testset/` (только звонки). Из общих файлов — своя строка в `modules/registry.*.ts`, `.env.example`, `package.json` (скрипт).
`packages/contracts` и `packages/core` не трогать; не хватает точки расширения — остановиться и написать владельцу.

## Что делает владелец (код не ждёт этого — работаем через симулятор)

- ❓ Аккаунт Voximplant, номер РФ (для номера могут попросить документы), приложение + правило на входящие с нашим сценарием.
- ❓ Публичный HTTPS-адрес API: сервер владельца или туннель (`cloudflared`) на ноутбуке. Записать в сценарий и `PUBLIC_API_URL`.
- Секрет `VOXIMPLANT_WEBHOOK_SECRET` — в `.env` и в сценарий (через `VoxEngine.customData` / настройки приложения), не в репозиторий.

## Критерии готовности

- **Работает в демо:** член жюри звонит на номер, говорит «не печатает принтер в 312-м», ИИ переспрашивает, кладёт трубку — заявка на экране диспетчера.
- `pnpm voice:sim` проходит весь путь без телефона.
- `pnpm check` зелёный, с выключенным модулем остальное работает. Нет новых замечаний SonarQube Blocker/Critical/Major.

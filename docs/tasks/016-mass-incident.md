## Что сделать

1. Шаг `mass.detect` (стадия `assess`): близость эмбеддингов или «категория + корпус / система» за окно; порог и окно — настройки.
2. Набралось N → инцидент, привязка заявок, высший приоритет, путь аварии (событие `mass.incident.opened`).
3. Веб: баннер «Похоже на общую аварию: N заявок», карточка инцидента со списком и хронологией.
4. Демо-маршрут (право админа): всплеск похожих обращений; `ClockPort` для тестов окна.
5. Тесты: успешный путь и каждая ветка ошибки; работа с выключенным флагом модуля.
6. `modules/<id>/README.md` и карта фичи в `docs/map/features/`.

## Критерии готовности

- **Работает в демо:** Нажали «всплеск» — заявки одна за другой склеиваются в инцидент, включается красный режим. Ментор п. 5.
- `pnpm check` зелёный, тест-контракт модулей проходит, с `FEATURES_OFF` этого модуля остальное работает.

## Что сделать

1. Шаг `clarify.missing` (стадия `validate`): пустые обязательные поля по реестру (с учётом `required.whenCategory`) → список `missing`.
2. Отправка вопросов-карточек из `FieldDef.ask` автоматически (шаблон), заявка → `waiting_applicant`.
3. Приём ответа: поле с `origin: asked`, след «спросили → ответил», `rerun(fromStage: validate)`.
4. Не больше 2 кругов; «не знаю» или таймер (настройка) → след «спросили — ответа нет → диспетчеру», заявка → `in_review`.
5. После разбора — шаблон «Заявка № … принята, приоритет …, срок …» заявителю автоматически.
6. Свободный текст от модели заявителю не отправлять (только после подтверждения диспетчера — задача 020).
7. Тесты: успешный путь и каждая ветка ошибки; работа с выключенным флагом модуля.
8. `modules/<id>/README.md` и карта фичи в `docs/map/features/`.

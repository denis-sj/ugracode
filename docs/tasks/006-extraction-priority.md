## Что сделать

1. **Адаптер Polza** (`packages/adapters/src/llm/polza.ts`): реализация `LlmPort.structured` через пакет `openai`
   с адресом Polza; температура 0; схема ответа из zod; проверка ответа, 1 повтор с текстом ошибки; запись в кэш.
   Модели — из `.env` (`LLM_MODEL_MAIN`, `LLM_MODEL_CHEAP`).
2. **Модуль `extraction`:**
   - шаг `extraction.fields` (стадия `extract`): один запрос к модели, промпт и схема собираются из реестра полей
     и аспектов; промпт — файл `prompts/extract.v1.md`; текст обращения — отдельным блоком «данные»;
   - запасной путь шага: правила (регулярные выражения для IP, кабинета, корпуса, кода ошибки + словарь категорий),
     уверенность 0,4;
   - шаг `extraction.ground` (стадия `validate`): 4 проверки из раздела 5.1 — цитата есть в тексте, значение из
     справочника и по `pattern`, сверка с CMDB, порог уверенности → `needsReview`;
   - для каждого поля — запись следа (`found` / `not_found` / `rejected` / `matched_cmdb`);
   - `progress()` по мере работы: интерфейс показывает поля по одному.
3. **Модуль `priority`:** поля `impact` и `urgency` (в `fields` модуля), шаг `priority.compute` — матрица из
   `data/priority-matrix.json`, поправки (критичность оборудования, авария, массовость — читать из черновика, если есть),
   срок SLA, текст «почему». Тональность не учитывать.
4. `evaluate()` у шагов — для будущего оценщика (014).
5. Тесты: успешный путь; модель вернула мусор → повтор → запасной путь; выдуманная цитата отбрасывается; значение
   вне справочника отбрасывается; каждая клетка матрицы приоритета; работа с выключенными модулями.
6. Карта: `docs/map/features/extraction.md`, `docs/map/features/priority.md`.

## Критерии готовности

- Пример заказчика («корпус Б, каб. 312, принтер HP, мигает красный индикатор») на `AI_MODE=cloud` даёт поля с
  цитатами и приоритет; на `AI_MODE=stub` — то же без сети.
- Обращение «опять ничего не работает» не порождает выдуманных полей.
- `pnpm check` зелёный, тест-контракт проходит.
- **Работает в демо:** в интерфейсе (после 007) видно, как поля появляются по одному.

## Что сделать

1. `packages/core/src/agent.ts`: `runAgent()` по разделам 2–3 спецификации — цикл до `maxSteps` (8), параллельные
   вызовы инструментов, итог только через `submit` с проверкой zod-схемой и `check()`, ошибки возвращаются модели.
2. **Шлюз выполнения:** инструмент есть в профиле агента и его `capability` разрешена роли пользователя; иначе вызов
   не выполняется, в след пишется `blocked`, модели уходит «недоступно».
3. `assembleSystemPrompt(profile, state)`: роль + описания разрешённых инструментов + состояние.
4. `defineModule`: поля `tools` и `agents`; реестры инструментов и агентов; имена инструментов уникальны.
5. `LlmPort.chat({ messages, tools, model })` + реализация для Polza (формат OpenAI: `tool_calls`, `finish_reason`),
   температура 0, фиксированный `seed`. Без кэша и повторов.
6. Заглушка модели — **сценарий**: заранее заданная последовательность вызовов инструментов и `submit`.
7. Таблица `agent_step` и запись каждого шага; события `agent.step` в поток SSE (инструмент, краткий итог, время).
8. Учёт расхода: токены, ₽ (цены модели — из настроек), миллисекунды — в `AgentRun.usage`.
9. Инструменты ядра: `dictionary_lookup`, `cmdb_find_equipment`, `cmdb_list_locations`.
10. Тест-контракт модулей: у инструмента есть описание, схема и право; агент ссылается только на существующие инструменты.
11. В `modules/_example` — один инструмент и один агент как образец.
12. Обновить [../map/README.md](../map/README.md) и `.env.example` (имена переменных; эмбеддинги помечены «не используются»).

## Критерии готовности

- Тесты на сценариях: успешный путь; запрещённый инструмент блокируется; несуществующий инструмент; неверные аргументы;
  `submit` не прошёл схему → модель исправляет; исчерпаны 8 шагов → `failed`; модель недоступна → `failed`.
- С ключом Polza: агент из `_example` делает вызов инструмента и сдаёт результат на `deepseek/deepseek-v4.1-flash`.
- `pnpm check` зелёный. Нет новых замечаний SonarQube уровня Blocker / Critical / Major.
- **Работает в демо:** шаги агента видны в потоке событий — интерфейс сможет показать «ИИ ищет…».

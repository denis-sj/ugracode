Первая задача фронтенда: общая основа, на которой потом перерисовываются экраны (задача 033).
Папки: `packages/ui/`, `apps/web/src/shell/`, `apps/web/src/screens/LoginScreen.tsx`. Модули не трогать.

## Что сделать

1. **Токены** (`packages/ui/src/tokens.css`): светлая тема — единственная и по умолчанию. Цвета, тени стекла,
   радиусы, шрифт Manrope — из [раздела 2 спецификации](../specs/case9-ui-design.md#2-стиль). Тёмную тему убрать.
2. **Фон приложения:** 2–3 размытых пятна (фиолетовое, синее, голубое) за всем интерфейсом, один раз в оболочке.
3. **Компоненты** в `packages/ui/src/components/` (переделать существующие, новые — по необходимости):
   - `Glass` (карточка), `GlassCapsule` (жидкое стекло шапки, без блика `::before`), `Sticker`;
   - `Button` — варианты `primary` (графит), `secondary` (прозрачная с обводкой), подсказка клавиши;
   - `PriorityMark` — круг-доля (раздел 3.4), `aria-label` со словом;
   - `Confidence` — проценты и тонкая шкала, жёлтая ниже 75% (раздел 3.6);
   - `OriginLabel` — подпись происхождения поля (раздел 3.5);
   - `AskCard` — карточка-вопрос как в Claude (раздел 4.1) — интерфейс компонента; логику вопросов делает модуль чата;
   - `Segmented`, `Chip`, `Checklist`, `StepBlock` (сворачиваемый шаг для проверки заявки).
4. **Шапка** (`AppShell`): «Диспетчерская» слева, капсула-меню по центру, справа круглые кнопки и аватар.
   Вкладки по роли — таблица раздела 3.1. Вид меню — **вариант, который выберет владелец** на доске
   `NavVariants.dc.html`; пока не выбрал — вариант A «Скользящая линза». Индикатор переезжает анимацией.
5. **Уведомления** — выпадающий блок под колокольчиком (раздел 3.2). **История** заявителя — панель справа (3.3).
6. **Вход** — по макету `Login.dc.html`: роль → пользователь → «Войти», карточка «Войти как гость».
7. `prefers-reduced-motion` отключает анимации. Тесты на чистые функции (меню по роли, формат процентов, доля приоритета).

## Критерии готовности

- **Работает в демо:** вход под каждой ролью показывает свою шапку со своими вкладками; уведомления и история открываются.
- В коде нет «сырых» цветов вне токенов, нет градиентных кнопок, нет блика на стекле (раздел 1 спецификации).
- Карта [ui-shell.md](../map/features/ui-shell.md) обновлена: светлая тема, новые компоненты.
- `pnpm check` зелёный; нет новых замечаний SonarQube уровня Blocker / Critical / Major.

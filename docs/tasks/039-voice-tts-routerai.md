Решение владельца (2026-11-14): озвучивать реплики ИИ-оператора **только** моделью `google/gemini-3.8-flash-lite-tts`
через провайдера **RouterAI** (а не `speechSynthesis` браузера). Это **единственное исключение** из правила
«модели только через Polza» ([../knowledge/environments.md](../knowledge/environments.md)): RouterAI используется только
для озвучки, разбор обращений остаётся на Polza.

Важно: это модель **текст → речь**. Она не распознаёт речь и не ведёт диалог. Цепочка звонка:
распознавание речи (Web Speech API браузера) → диалоговый шаг LLM (Polza, как в 036) → **озвучка (эта задача)**.

## Что сделать

1. **Адаптер озвучки** (порт в `packages/core`, реализация в `apps/api`): `speak(text, voice?) → аудио`. Реализация
   RouterAI; заглушка для тестов и режима без ключа. Ключ только из `.env` (`ROUTERAI_API_KEY`), в логи и ответы
   не попадает ([../rules/secrets-and-data.md](../rules/secrets-and-data.md)).
2. **Эндпоинт** `POST /api/tts` (доступ: роль, которой разрешён звонок; лимит длины текста, например ≤ 400 символов;
   кэш по хэшу текста и голоса, чтобы повторные фразы не стоили денег).
3. **Страница звонка** (`/call`, задача 036): реплика ИИ приходит текстом, показывается на экране сразу, аудио
   воспроизводится по готовности. Первая фраза («Здравствуйте, диспетчерская…») и типовые уточнения предсинтезируются
   заранее, чтобы не было паузы.
4. **Номер заявки голосом.** В конце звонка оператор называет номер в новом простом формате («заявка шестьсот два»)
   — число в текст для озвучки превращает сервер (слова, а не цифры), см. [038](038-ui-polish-round2.md) п. 7.
5. **Сбой.** Нет ключа, нет сети, ответ дольше ~3 с → фраза остаётся на экране текстом; ❓ нужен ли запасной вариант
   `speechSynthesis` (вопрос владельцу ниже).
6. **Тесты:** заглушка адаптера, кэш, лимит длины, ключ не попадает в ответ и лог, преобразование номера в слова.
7. **Проверка API:** скрипт `pnpm check:routerai` по образцу `check:polza`: доступность модели, формат ответа
   (формат аудио, длительность), замер задержки на русской фразе. Результат записать в `docs/knowledge/environments.md`.

## Решения владельца и факты о RouterAI (проверено 2026-11-14)

- Озвучка нужна **только в звонке по QR** (036), в чате заявителя не нужна. Номер заявки в конце звонка называется словами.
- **Запасной голос оставляем:** при сбое RouterAI (нет ключа, нет сети, ответ дольше ~3 с) озвучивает `speechSynthesis` браузера.
- Базовый URL: `https://routerai.ru/api/v1`. Ключ владелец кладёт в `.env` как `ROUTERAI_API_KEY` (в чат не присылать).
- Эндпоинт: `POST /audio/speech`, формат как у OpenAI Audio Speech, заголовок `Authorization: Bearer <ключ>`.
  Тело: `{"model": "google/gemini-3.8-flash-lite-tts", "input": "<текст>", "voice": "Kore", "response_format": "pcm"}`.
  Ответ: сырой аудиопоток (не JSON), заголовок `X-Generation-Id`; ошибки приходят JSON с кодом не 200.
- **Gemini TTS отдаёт только `pcm`: 16 бит, 24 кГц, моно; запрос `mp3` для них падает.** Браузер PCM сам не играет:
  сервер оборачивает PCM в WAV-заголовок (44 байта), результат кэшируется и играется обычным `<audio>`.
- Голос: параметр `voice`. У Gemini TTS 30 студийных голосов, в документации RouterAI примеры `Kore` и `Charon`;
  русскоязычный голос выбираем по результатам `check:routerai`.
- Лимит тела запроса 32 МБ; длинные тексты резать на короткие фразы (первый звук быстрее).
- Каталог `GET /api/v1/models` (ключ не нужен) подтверждает модель `google/gemini-3.8-flash-lite-tts`: вход text, выход speech,
  контекст 32768, тариф за токены: вход 5.34e-05 и выход 6.41e-04 за токен (≈ 53 ₽ и ≈ 641 ₽ за 1 млн токенов на 2026-11-14).

## Стоимость

Реплика на 10–15 секунд — порядка 250–400 аудио-токенов (оценка, около 25 токенов в секунду), то есть примерно
0,2–0,3 ₽. Сотня реплик на репетициях и защите — порядка 25 ₽. Повторяющиеся фразы кэшируются. Точный расход
смотреть в кабинете RouterAI после первых замеров.

## Критерии готовности

- Живой звонок: реплика ИИ появляется текстом сразу, голос звучит без заметной паузы (цель ≤ 2 с после текста).
- Ключ не виден ни в интерфейсе, ни в сети, ни в логах; без ключа система работает текстом.
- Нет новых замечаний SonarQube Blocker/Critical/Major; `python3 -m unittest discover -s tests` проходит.
- Проверено в браузере (ноутбук и телефон по QR).

## Блокеры

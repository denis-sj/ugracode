| Вопрос | Ответ владельца |

| Скиллы | «Если нужно, пусть агент использует нужный скилл superpowers» |

## Что решили

1. **Только облако (Polza), локальные модели не ставим.** Закрытый контур остаётся портом в архитектуре и слайдом
   «как ставится локально» — ментор это допускал («показать на общедоступных моделях с пояснением»).
   Переключатель «облако / локально» в интерфейсе заменён индикатором контура.
2. **Модели** (каталог Polza проверен на сайте): разбор текста и скриншотов — Claude Haiku 5.5; дешёвые задачи —
   DeepSeek V4.1 Flash; эмбеддинги — BGE Multilingual Gemma2; речь — GigaAM-v3. Окончательно — по цифрам оценщика
   на тестовом наборе. ❓ Технические детали API проверяет первая задача кода.
3. **Архитектура:** модульный монолит, маленькое ядро + модули фич, 10 точек расширения. Стек: pnpm-монорепо,
   Fastify, zod, PostgreSQL + pgvector, Drizzle, React + Vite, Tailwind, Framer Motion, ECharts.
4. **Обязательные функции брифа оформлены как модули** — проверка, что точки расширения работают.
5. **План под чекпоинт через 2 часа:** поток 0 (каркас, 35 минут) → три параллельных потока (разбор, интерфейс,
   данные) → сборка. К чекпоинту — «текст → заявка».

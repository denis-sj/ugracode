## Демо-стенд

| Что | Как |
|---|---|
| Основной стенд | ноутбук владельца, `docker compose up -d --build` → веб http://localhost:5173, API http://localhost:3001 |
| Запасная копия | сервер владельца, адрес ❓; тот же `docker-compose.yml` и `.env`, проверка `pnpm demo:check --base-url http://<сервер>:3001` |
| Режим с ключом | `AI_MODE=cloud` + `POLZA_API_KEY` в `.env`; разбор, статья базы знаний и вывод отчёта — от модели (`deepseek/deepseek-v4.1-flash-1017`) |
| Режим без ключа | `AI_MODE=stub`; поля даёт модуль-образец по правилам, авария — правила, вывод отчёта — шаблон; на защите честно говорить «демо-режим» |
| Сброс данных | `pnpm demo:reset` (`packages/db/src/seed/index.ts --reset`): очищает демо-таблицы и засевает заново 600 заявок истории, пользователей, CMDB, статьи. ❗ 2026-11-14 падает на `ai_cache` (таблицы больше нет) — нужна правка одной строки в сиде; обходной путь `docker compose down -v && docker compose up -d --build` |
| Смоук перед защитой | `pnpm demo:check` (облако, 45–60 с) или `pnpm demo:check --stub` (без ключа, 1–3 с); код 1 — на защиту не выходить |

Замеры 2026-11-14 (локальный Compose, облако Polza): смоук 46–55 с; разбор обращения 17–28 с;
авария 17 с; отчёт смены 3–5 с. На заглушке весь смоук 0,3 с. Подробности — [demo-script.md](../hackathon/demo-script.md#подготовка-за-10-15-минут).

Сеть: основной вариант демо рассчитан на интернет (облако Polza). Запасная копия нужна
на случай сбоя ноутбука или сети; кэша ответов модели нет — офлайн-режим не поддерживается
(решение владельца 2026-11-14), см. [limitations.md](limitations.md).

## Стек

**Решение владельца 2026-11-14: весь проект на TypeScript, бэкенд на Node.js.** Конкретные библиотеки
и фреймворки выбирает архитектор в спецификации. Рабочее предложение:

- Фронтенд: TypeScript (React / Next.js), Tailwind CSS, Framer Motion (анимации), Recharts или ECharts (графики).
- Бэкенд: **Node.js + TypeScript** (фреймворк — ❓ решает архитектор).
- База: PostgreSQL + pgvector (поиск похожих заявок и статей базы знаний).
- ИИ: слой-адаптер над LLM, чтобы облачную модель можно было заменить на локальную.
- Инфраструктура: Docker Compose.

**Стек утверждён в спецификации** [../specs/case9-core.md](../specs/case9-core.md#11-стек): pnpm-монорепо,
Fastify, zod, PostgreSQL + pgvector, Drizzle, React + Vite, Tailwind, Framer Motion, ECharts, Vitest.

Провайдер модели ИИ: **Polza** (polza.ai; API по стандарту OpenAI Chat Completions). **Только облако —
локальные модели не разворачиваем** (владелец, 2026-11-14). Модели (обновлено 2026-11-14 по каталогу
`https://api.polza.ai/api/v1/models`): `openai/gpt-6-luna` (разбор), `deepseek/deepseek-v4-flash` (дешёвые задачи),
`baai/bge-m3` (эмбеддинги), `ai-sage/gigaam-v3` (речь) — таблица и цены в
[спецификации](../specs/case9-core.md#54-модели-polza). Адрес API — `https://api.polza.ai/api/v1`.
**Решение владельца (позже в тот же день):** одна модель `deepseek/deepseek-v4.1-flash` для разбора и отчётов;
эмбеддинги не используются (агент с инструментами вместо RAG) — [спецификация харнесса](../specs/case9-agent-harness.md#6-модель).
Имена моделей в `.env` — **с префиксом провайдера** (`deepseek/…`, `ai-sage/gigaam-v3`).
❓ Вживую с ключом не проверено.

Секреты (ключи LLM): ключ есть у владельца, в репозиторий не кладётся — только `.env` (в `.gitignore`) и `.env.example` с пустым значением.

## Проверка API Polza (2026-11-14, ключ владельца)

Скрипт: `pnpm check:polza` (`scripts/check-polza.ts`). Ключ читается только из `.env`, в вывод не попадает.

| Что проверяется | Результат |
|---|---|
| Чат и `response_format: json_schema` | **работает** — `deepseek/deepseek-v4.1-flash-1017` |
| Вызов инструментов (`tool_calls`, finish_reason) | **работает** на той же модели |
| Другие chat-модели каталога (`deepseek-v4.1-flash`, Claude Haiku, Qwen, Gemma, Mistral) | **403**: «модель недоступна для данного API-ключа» |
| Эмбеддинги (BGE, OpenAI, Gemini, Qwen) | **403** на этом ключе (по решению 2026-11-14 не используются) |
| Распознавание речи (GigaAM-v3, Whisper) | **403** на этом ключе — нужен запасной вариант `whisper.cpp` на ноутбуке или расширение доступа |

Модель для обеих переменных — `deepseek/deepseek-v4.1-flash-1017`; снимок без суффикса `-1017` ключу недоступен.
Адрес API `https://api.polza.ai/api/v1` подтверждён. Если доступ к речи нужен через API — попросить владельца
включить модель в кабинете Polza; до тех пор `POST /api/transcribe` на облаке отвечает 502, на заглушке работает.

## Проверка озвучки RouterAI (2026-11-14, ключ владельца)

Скрипт: `pnpm check:routerai` (`scripts/check-routerai.ts`). Ключ читается только из `.env` (`ROUTERAI_API_KEY`),
в вывод не попадает. RouterAI — **единственное исключение** из правила «модели только через Polza»: только озвучка,
разбор обращений остаётся на Polza.

| Что проверяется | Результат |
|---|---|
| Каталог `GET /api/v1/models` без ключа | `google/gemini-3.8-flash-lite-tts` есть; тариф 5.34e-05 / 6.41e-04 за токен (≈ 53 ₽ / 641 ₽ за 1 млн) |
| `POST /audio/speech`, `response_format: pcm` | **работает**: 200, `content-type: audio/pcm` |
| Что реально в теле ответа | **готовый RIFF/WAVE**: 16 бит, моно, 24 кГц, 44-байтный заголовок уже есть. Обёртка PCM→WAV нужна как страховка и должна быть идемпотентной, иначе двойной заголовок ломает звук |
| `response_format: mp3` | **не падает**: тот же WAV, `content-type: audio/pcm` — mp3 как таковой не отдаётся, поэтому играем WAV |
| Задержка живого запроса, фраза 62 символа | **1,7–2,5 с** (9 замеров, 4 голоса), длительность аудио 4,2–5,3 с |
| Голоса на русской фразе | Kore 1,7–2,3 с · Charon 2,0–2,5 с · Puck 1,8–2,4 с · Aoede 1,9–2,1 с |
| Разборчивость по кругу (синтез → распознавание) | не измерить: ключ Polza отдаёт **403** на всех ASR-моделях (см. таблицу выше). Образцы лежат в `.demo/tts/*.wav` (в git не идут) |

**Голос по умолчанию — `Kore`** (`ROUTERAI_TTS_VOICE`): женский, ровный диспетчерский тон, самый быстрый из стабильных.
Владельцу перед защитой стоит прослушать четыре файла в `.demo/tts/` и при желании переключить голос одной переменной
в `.env` (`Charon` — низкий мужской, `Aoede` — мягкий женский, `Puck` — бодрый мужской); код менять не нужно.

Вывод для демо: **живой синтез один не укладывается в цель ≤ 2 с** (1,7–2,5 с на фразу). Поэтому первая фраза
и типовые уточнения синтезируются заранее по жесту «Ответить», повторные фразы берутся из кэша сервера
(хэш текста и голоса в памяти процесса, ≤ 200 записей) — на защите звук стартует без паузы. Сбой (нет ключа/сети,
ответ дольше 3 с) — запасной `speechSynthesis` браузера, текст реплики остаётся на экране.
Стоимость: реплика 10–15 с ≈ 250–400 аудио-токенов ≈ 0,2–0,3 ₽; сотня реплик на репетициях и защите ≈ 25 ₽.

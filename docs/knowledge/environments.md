|---|---|---|
| Локальная разработка | macOS владельца | есть |

## Предлагаемый стек (черновик, утверждается в спецификации)

Утверждён будет после выбора кейса. Рабочее предложение для кейса 9:

- Фронтенд: Next.js + TypeScript, Tailwind CSS, Framer Motion (анимации), Recharts или ECharts (графики).
- Бэкенд: Python, FastAPI.
- База: PostgreSQL + pgvector (поиск похожих заявок и статей базы знаний).
- ИИ: слой-адаптер над LLM, чтобы облачную модель можно было заменить на локальную.
- Инфраструктура: Docker Compose.

Секреты (ключи LLM): не заданы.

## Почему переделываем

Сейчас слишком много текста, на каждом слайде по 3–5 блоков в карточках, а цифр мало и они мелкие. Нужно, как в образце: **одна мысль на слайд, одна огромная цифра, минимум слов, красивые анимации.** Оформление образца не копировать (там свой бренд, лиса, оранжевый). Берём только подачу.

## Что взять из образца

1. **Одна главная цифра на слайд**, очень крупно (у 1920×1080 это 260–380 px, Manrope 800, `letter-spacing: -0.04em`, `font-variant-numeric: tabular-nums`). Под цифрой одна строка пояснения (28–36 px). Всё остальное мелко и серым.
2. **Заголовки до 6 слов, без абзацев.** Если строку можно убрать без потери смысла, убираем.
3. **Таблицы из тонких горизонтальных линий** (1 px, серые). Без карточек, теней, скруглённых плашек и градиентных пятен на фоне.
4. **Рукописные акценты:** неровное подчёркивание под ключевым словом, овал-обводка вокруг главной цифры, зачёркивание «было». Делать inline-SVG `path` со слегка дрожащей линией (stroke ~4–6 px, `stroke-linecap: round`). При показе слайда они **дорисовываются** через `stroke-dasharray`/`stroke-dashoffset` (GSAP, 0.6–0.9 с).
5. **Тихая рамка:** сверху мелко (14 px) слева «Диспетчерская с ИИ.» (точка акцентным цветом), справа название раздела («Проблема», «Точность», «Польза»…). Поля 96 px.
6. **Анимации:** цифра набегает счётчиком от 0 (0.8–1.2 с, `power3.out`), строки таблицы появляются по одной снизу с лёгким сдвигом (stagger 0.08 с), заголовок — из маски снизу вверх. Всё быстро и спокойно, без вращений и прыжков. При `prefers-reduced-motion` и в режиме `?print` всё сразу в финальном состоянии.

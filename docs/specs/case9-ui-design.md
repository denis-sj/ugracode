# Дизайн интерфейса кейса 9 — стиль, экраны, взаимодействия

Статус: active
Дата: 2026-11-14
Связано: [../../AGENTS.md](../../AGENTS.md), [../prompts/frontend-kickoff.md](../prompts/frontend-kickoff.md), [../hackathon/case9-brief.md](../hackathon/case9-brief.md), [case9-features.md](case9-features.md), [../map/features/ui-shell.md](../map/features/ui-shell.md)

Утверждённый владельцем внешний вид системы. Это **источник правды для фронтенда**: если код или старые
задачи расходятся с этим файлом — прав этот файл. Закрывает критерии кейса К3 (проверка и правка
заявки диспетчером) и подачу «вау» на защите ([criteria.md](../hackathon/criteria.md)).

- **Макеты:** холст Design-артефакта (ссылку даёт владелец) и копии экранов в [ui-mockups/](ui-mockups/).
  Файлы `*.dc.html` — макеты, не код приложения: смотреть разметку, цвета, тексты и логику
  в блоке `<script type="text/x-dc">`. Переносить в React-компоненты, а не копировать как есть.
- Цифры, имена и заявки в макетах выдуманы. В приложении всё берётся из API и синтетики.

## 1. Что владелец запретил («нейрослоп»)

Не делать, даже если «так красивее»:

- тёмную тему, «ночной собор», красно-оранжевые фоны и баннеры на весь экран;
- градиентные кнопки со свечением (фиолетовый → синий, цветная тень);
- блик-полосу (`::before`) поверх стеклянных капсул и кнопок;
- подчёркивание ключевых слов маркером — ключевое выделяется **жирным** (`<strong>`), его расставляет модель при генерации;
- боковую панель-сайдбар у заявителя;
- приоритет словами в таблицах — только индикатором (см. 3.4);
- лишние блоки «для красоты»: статистику заявителя, отдельную вкладку профиля, «Частые вопросы».

## 2. Стиль

| Что | Значение |
|---|---|
| Тема | **Только светлая.** Фон `#F5F6FB` |
| Шрифт | **Manrope** 400–800, кириллица |
| Атмосфера | 2–3 больших размытых пятна: фиолетовое `rgba(123,77,255,.24)` слева сверху, синее `rgba(2,125,234,.2)` справа сверху, голубое `rgba(182,217,252,.5)` снизу. На экране обращения — едва заметная сетка 80 px |
| Текст | основной `#0F1222`, вторичный `#5B6178`, подписи `#8A90A6` |
| Заголовок страницы | 34–40 px, 700, градиент текста `#0F1222 → #5A49E0` |
| Акцент | фиолетовый `#5A49E0` — только выделение выбранного и ссылки, **не заливка кнопок** |
| Статусы | ок `#0E8A5F`, внимание `#B26A00` / `#E0A100`, информация `#027DEA`, авария `#D4380D` — только точкой, текстом или тонкой линией, не фоном экрана |

### 2.1 Стекло

- **Карточка:** белый градиент `rgba(255,255,255,.8) → .58`, `backdrop-filter: blur(20px) saturate(160%)`,
  радиус 18, внутренняя обводка `1px rgba(255,255,255,.9)`, тень `0 12px 40px rgba(40,46,110,.10)`.
- **«Жидкое стекло» шапки** (капсула меню, круглые кнопки 44 px): радиальный белый градиент,
  `inset 0 1px 1px #fff`, `inset 0 -3px 8px rgba(110,120,210,.16)`, тонкая внешняя обводка. Без блика.
- **Стикер** (заявка рядом с чатом, превью в очереди): плотнее (`.9 → .72`), шапка с лёгким
  фиолетово-синим градиентом, у заявителя — поворот 0,6°.

### 2.2 Кнопки

- **Главная:** графит `#14172B`, белый текст, `inset 0 1px 0 rgba(255,255,255,.12)`, без свечения; hover `#262A45`.
- **Второстепенная:** прозрачная, обводка `inset 0 0 0 1px rgba(15,18,34,.16)`; hover — белая заливка.
- Высота 42–48 px, радиус 10–12. Подсказка клавиши (`Enter`) — маленькая плашка внутри кнопки.

### 2.3 Анимации

Появление снизу (`rise`, 0,4 с), выезд панелей справа, шкала заполняется плавно, новые строки очереди
въезжают сверху со вспышкой. Всё отключается при `prefers-reduced-motion`.

Как это реализовано и что делать на новом экране — [правила анимаций](../rules/animations.md)
(GSAP — появление блоков, AutoAnimate — списки, Motion — пружинные окна, canvas-confetti — «заявка назначена»).

## 3. Общие элементы

### 3.1 Шапка (одна на все роли)

Слева «Диспетчерская», по центру — капсула-меню, справа — круглые кнопки и аватар (градиентный круг
с инициалами, ведёт в профиль). **Вид меню — вариант E «Вдавленное стекло с иконками»** (выбор владельца 2026-11-14, доска
`NavVariants.dc.html`): иконка над подписью, активная вкладка вдавлена внутрь стекла (внутренняя тень,
фиолетовый текст и иконка), без выпуклой таблетки; счётчики — маленькие круги рядом с подписью. **Вкладки зависят от роли:**

| Роль | Вкладки | Кнопки справа |
|---|---|---|
| Заявитель | Обращение · Мои заявки | история, уведомления, аватар |
| Диспетчер | Очередь (счётчик) · Аварии (счётчик красным) · Журнал · Исполнители | уведомления, аватар |
| Инженер | Мои задачи (счётчик) · База знаний | уведомления, аватар |
| Руководитель | Дашборд · Отчёты · Качество ИИ · С ИИ / без ИИ | уведомления, аватар |

### 3.2 Уведомления

Колокольчик открывает **выпадающий блок** под ним (не отдельную страницу): список, непрочитанные
подсвечены, «Прочитать все».

### 3.3 История обращений (заявитель)

Кнопка-список в шапке выезжает **панелью справа** поверх страницы: поиск, группы «Активные» и «Ранее»,
у каждой — номер, дата, статус цветным текстом. Закрывается крестиком или кликом мимо.

### 3.4 Приоритет

Круг 16 px, закрашенный на долю (как «шар Харви»): низкий — четверть, средний — половина,
высокий — три четверти, критический — целиком. Графит, у критического — `#D4380D` и красная
полоска 3 px у левого края строки. Слово — только в `aria-label`/подсказке и в шапке превью.
(Полоски-«сигнал» владелец отклонил.)

### 3.6 Уверенность ИИ

Всегда в процентах: «94%», порог сомнения — 75%. Не «0,94».

### 3.5 Происхождение поля

У каждого поля заявки — подпись, откуда значение: «из текста: «цитата»» (фиолетовый), «сверено с базой
оборудования» (зелёный), «ответ заявителя» (синий), «ИИ не уверен — выберите» (жёлтый), «исправил
диспетчер» (зелёный). Это и есть след «нашёл → спросил → отдал диспетчеру» из [брифа, раздел 1а](../hackathon/case9-brief.md#1а-что-сказал-ментор-2026-11-14--меняет-приоритеты).

### 4.1 Обращение (заявитель)

- **Старт:** по центру «Что случилось?» и большое стеклянное поле с подсказкой-примером.
  Под полем: скрепка (фото/скриншот), микрофон (голос), телефон (позвонить), круглая графитовая «отправить».
- **Ответ ИИ** — обычный текст без пузыря, ключевое жирным. Сообщения заявителя — справа.
  Пока модель думает — строка с переливом («Разбираю обращение»).
- **Карточка-вопрос, как в Claude:** заголовок-вопрос, счётчик «1 из N» со стрелками назад/вперёд,
  варианты списком с номерами 1, 2, 3 (у варианта может быть подпись, например «Указан в вашем
  профиле»), пункт «Не знаю — диспетчер уточнит сам», **строка «Свой вариант» с полем ввода**,
  внизу «Пропустить» и «Ответить Enter». Цифры на клавиатуре выбирают вариант. Лимита вопросов нет.
- **Стикер «Ваше обращение» справа:** появляется после первого ответа ИИ и заполняется по ходу:
  «уточняем…» → значение. Статус, шкала «Собрана → Проверена → Назначена → Выполнена», в конце — инженер и срок.
  Заявка **не** пишется в ленту чата.

### 4.2 Мои заявки

Переключатель «Активные / Закрытые». Сверху — заявка, ждущая подтверждения: «Да, всё работает» /
«Вернуть инженеру». Ниже — строки: название, номер и статус, шкала из 4 сегментов, исполнитель и срок.
Профиль — отдельная страница (ещё не нарисована, ❓ уточнить у владельца состав).

### 4.3 Очередь (диспетчер)

Сводка цифрами справа от заголовка (ждут проверки, ждут заявителя, за смену и % без правок).
Таблица: приоритет (полоски) · обращение (название, номер, место) · уверенность ИИ (тонкая шкала, жёлтая
ниже 0,75) · сколько ждёт · что сделать (точка-статус + текст). Фильтры: Все / Сомнительные / Готовые / Аварии, поиск.
Справа — стикер-превью выбранной заявки: исходная цитата, поля с происхождением, предложенный исполнитель
с объяснением, «Подтвердить Enter» и «Открыть».

### 4.4 Проверка заявки — шаги по блокам

Четыре блока по порядку: **Обращение → Поля заявки → Исполнитель → Ответ заявителю**. Открыт один,
остальные свёрнуты в строку с номером/галочкой и итогом («6 полей, 1 ждёт вас»), к любому можно
вернуться кликом. Внизу открытого блока — кнопка к следующему.

- *Обращение:* текст с жирным ключевым и след «Нашёл → Сверил → Спросил → Вам».
- *Поля:* поле, значение, происхождение, уверенность. Сомнительное подсвечено жёлтым и предлагает
  варианты одним кликом; после выбора — «исправил диспетчер, ИИ предлагал …» и запись в журнал.
- *Исполнитель:* топ-3 с процентом совпадения; клик показывает справа причины (похожие решённые,
  загрузка, смена, корпус).
- *Ответ заявителю:* редактируемый черновик ИИ, «Подтвердить и назначить Enter», «Вернуть заявителю».

Справа закреплён «Итог заявки»: шкала шагов, ключевые поля и **счётчик действий диспетчера** (для К4).
После подтверждения — окно «Назначена» с переходом к следующей заявке.

### 4.5 Авария и массовость

Тот же светлый стиль, авария — красной пульсирующей точкой и красным текстом, без красного фона.
Шапка-карточка: номер, канал, цитата с признаками, таймер с момента звонка, «почему авария»,
уверенность, ответственный. Ниже три карточки: регламент (5 пунктов, отмечаются), хронология (точки по
времени), «Похоже на массовый сбой» (растущий счётчик, столбики по минутам с пунктирной линией
порога, кнопка «Объявить массовым инцидентом» → номер инцидента и одно сообщение всем заявителям).

### 4.6 Инженер

Слева список задач на сегодня. По центру — задача: срок по регламенту, заявитель, статус, «Взять в
работу». Диагностика — шаги из статьи базы знаний с отметками («помогла в 9 из 11 случаев»).
Похожие решённые заявки и предупреждение о частых поломках устройства. Результат: быстрые варианты,
поле «что сделано», «Сохранить как статью», «Выполнено» / «Продлить срок» / «Вернуть диспетчеру».

### 4.7 Дашборд и отчёт (руководитель)

- Период: Смена / 7 дней / 30 дней / Квартал + **выбор дат**; сравнение с прошлым таким же периодом.
- **Фильтры:** категория, исполнитель, канал, объект, статус (сочетаются).
- **Выгрузка (меню):** Excel по листам, PDF-отчёт с выводами, CSV заявок, «Отправить на почту»,
  «Присылать сводку по понедельникам».
- 5 плиток с ▲/▼; клик по цифре открывает заявки.
- График по приоритетам, тепловая карта «день × час», под каждым — «Что это значит».
- Отчёт «Горячие точки оборудования» с блоками «Что это значит» и «Что сделать». Цифры считает код, ИИ только формулирует.
- Остальные разрезы и отчёты О1–О8 — [бриф, раздел 8а](../hackathon/case9-brief.md#8а-отчётность-полезные-отчёты-с-объяснением).

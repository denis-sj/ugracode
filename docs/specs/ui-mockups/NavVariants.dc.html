Меню в шапке: 5 вариантов

Все в стекле, без блика. Кликните по вкладкам — индикатор переезжает.
A · Скользящая линзаПрозрачная капсула, по ней скользит отдельная линза из более плотного стекла. Счётчики — маленькие круги.
B · Тонкая линияМатовое стекло без выделенной таблетки. Активная вкладка — тёмный текст и графитовая линия 2 px, она переезжает.
C · Графитовая таблеткаСтеклянная капсула, активная вкладка залита графитом — как главные кнопки. Самый контрастный вариант.
D · Отдельные стёклаКаждая вкладка — своё маленькое стекло с промежутком. Активная плотнее и с тонкой тёмной обводкой.
E · Вдавленное стекло с иконкамиИконка над подписью. Активная вкладка будто вдавлена в стекло: внутренняя тень вместо выпуклой таблетки.

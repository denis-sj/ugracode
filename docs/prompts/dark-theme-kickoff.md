# Промпт: тёмная тема интерфейса (кейс 9)

Назначение: дать агенту фронтенда задачу «тёмная тема как второй режим». Решение и значения цветов записаны в
[case9-ui-design.md](../specs/case9-ui-design.md), раздел 2.4. Эталон на холсте Design-артефакта:
https://claude.ai/artifact/3LqKwphtxf7KX8sb2cpXfE (в каждом экране есть переключатель луна/солнце).

Как использовать: открыть новую сессию в папке репозитория и написать: «ты Семён, выполни
docs/prompts/dark-theme-kickoff.md». Блок ниже агент тоже получит; если нужно, его можно вставить целиком.

```text
Ты Семён — кодер проекта (роль в AGENTS.md). Задача: добавить ТЁМНУЮ ТЕМУ как второй режим интерфейса системы «Диспетчерская с ИИ» (кейс 9). Светлая тема остаётся по умолчанию. Функционал не трогаем, меняем только оформление и переключатель.

КОНТЕКСТ
- Источник правды: docs/specs/case9-ui-design.md — разделы 1, 2, 2.4 (тёмная тема), 3.1 (шапка), 6 (расхождения с кодом). Читай его первым.
- Эталон: холст Design-артефакта https://claude.ai/artifact/3LqKwphtxf7KX8sb2cpXfE — во всех 16 экранах уже есть тёмная тема и переключатель луна/солнце в шапке. Значения цветов ниже совпадают с холстом. На холсте переключатель сделан CSS-only (:has) только для макетов; в приложении сделай по-настоящему (см. п. 2).
- Правила: docs/rules/animations.md, docs/rules/code-quality.md, docs/rules/testing.md, карта docs/map/features/ui-shell.md (там сейчас написано, что тёмная тема по умолчанию — это исправить).

ЧТО СДЕЛАТЬ
1. Токены. Все цвета — только через CSS-переменные. Светлый набор — по умолчанию (:root). Тёмный — при data-theme="dark" на <html>. Hex и rgba прямо в компонентах не оставлять. Место: токены дизайн-системы в packages/ui/src/styles.css (сверь, где они уже лежат, и не дублируй).
2. Переключатель. Кнопка в шапке AppShell (apps/web/src/shell/), слева от колокольчика (NotificationsButton). Иконка: луна в светлой теме, солнце в тёмной. Это <button aria-label="Тёмная тема" aria-pressed="…"> в стиле соседних кнопок шапки (44 px, круглая, стекло). Состояние — React state, атрибут data-theme ставится на <html>. Выбор сохранять в localStorage: чтение и запись в try/catch, если хранилище недоступно — просто не сохранять. Системную тему (prefers-color-scheme) по умолчанию НЕ использовать.
3. Без вспышки. Тема применяется до первого рендера (скрипт в <head> или чтение в инициализации), иначе при загрузке тёмной страницы мелькает светлая.
4. Компоненты. Пройди все экраны и общие элементы: карточки-стекло, капсула меню, кнопки, поля ввода, чипы, круги приоритета, статусы, стикер заявки, выпадающие уведомления, история обращений, модальные окна. Из packages/ui: ConfidenceBar, Modal, ProgressScale, StepBlock. Все жёстко заданные цвета (#fff, #0F1222, rgba(...)) — на токены.
4а. Экраны, которые обязательно пройти (все утверждённые, docs/specs/case9-ui-design.md, раздел 4): Обращение (чат), Мои заявки, Очередь, Проверка заявки, Авария и массовость, Задача инженера, Дашборд и отчёт, Вход, Профиль, Голос и фото, Журнал действий, Исполнители, База знаний, Качество ИИ, С ИИ / без ИИ. Плюс шапка (вариант E) и все выпадающие и боковые панели. Каждый экран — в обеих темах.
5. Фон. Три размытых пятна (фиолетовое, синее, голубое) в тёмной теме тише и темнее — значения в таблице.
6. Документы: обнови docs/map/features/ui-shell.md (тёмная — второй режим, не по умолчанию) и, если нужно, docs/map/recipes.md. Спека уже обновлена — сверь её с реализацией и поправь, если разошлось.

ЗАПРЕТЫ (в обеих темах)
- Никакого «ночного собора», красно-оранжевых фонов и баннеров на весь экран.
- Градиентных кнопок со свечением. Блика ::before на стекле и кнопках.
- Подчёркивания маркером: ключевое выделяем жирным.
- Заливка кнопок только графитом (в тёмной — светлой). Фиолетовый — для выбора и ссылок, не для заливки.
- Статусы — точкой, текстом или тонкой линией, не фоном экрана.

ОГРАНИЧЕНИЯ РАБОТЫ
- Работай в ветке, не в main. Ничего не коммить, пока владелец не попросит.
- В рабочем дереве много незакоммиченных правок других потоков (apps/web, modules/*). Не откатывай их и не трогай чужие файлы. Меняй только то, что нужно для темы. Если файл в чужой зоне или его нет — спроси, не угадывай.
- Сначала пришли короткий план (что править и в каком порядке). Код начинай после «ок» владельца.
- Тесты: переключение темы, сохранение выбора в localStorage, поведение при недоступном localStorage, светлая тема по умолчанию. Типы и линтер проходят.
- Проверь в браузере переключатель на каждом экране (Заявитель, Диспетчер, Инженер, Руководитель, Вход), читаемость текста (контраст не ниже 4,5:1), отсутствие вспышки при загрузке.
- Анимации — по docs/rules/animations.md. Смена темы — только плавный переход цвета ~0,2 с; при prefers-reduced-motion переход отключён.

Цель проекта — 1-е место. Тёмная тема — вторичная: не должна сломать демо-сценарий светлой.
```

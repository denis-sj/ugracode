# Модуль `executors` — экран 12 «Исполнители»

Веб-часть диспетчера `/executors` (роли `dispatcher`, `admin`, `manager`): карточки из `GET /api/engineers`,
фильтр по подразделению, переключатель «Только на смене» и поиск; клик — панель «Текущие задачи»
(`GET /api/tickets?assigneeId=<id>&limit=20`, ссылка `#/review?id=…`). Только чтение, своих маршрутов нет.
Загрузка считается от порога 5 заявок: 4 — «почти предел», 5 и больше — «перегруз»; перегруженные и
смена сверху. Пустые состояния, `useListMotion`, `data-reveal`, только токены `@ugra/ui`.

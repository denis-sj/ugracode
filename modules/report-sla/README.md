# Модуль `report-sla`

Что делает: отчёт О3 «Сроки (SLA)» — доля закрытых в срок, нарушения по закрытым и открытым заявкам, заявки под риском, среднее время реакции и решения, разрезы по приоритетам и подразделениям, топ-5 худших заявок; вывод «что это значит / что сделать» — модель `cheap` по фактам, при ошибке — шаблон.
Флаг фичи: `enabledByDefault: true`; выключение — `FEATURES_OFF=report-sla`.
Точки расширения: `reports` (`sla.summary`), маршруты `GET /api/m/report-sla/`, `POST /api/m/report-sla/run`, `GET /api/m/report-sla/export?format=csv` (право `reports`), `drilldown` → фильтр заявок.
Данные: заявки и журнал событий (`ticket.status.changed`, `ticket.assigned`) из `KernelStore`; своих таблиц нет.
Момент демо: руководитель видит, где опаздываем, и открывает пятёрку худших заявок прямо из отчёта.

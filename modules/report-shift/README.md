# Модуль `report-shift`

Что делает: отчёт О1 «Сводка смены» — всего/новые/закрытые/аварии и «в срок %» за день, нагрузка по исполнителям, просроченные заявки и заявки, ждущие проверки; вывод «что это значит / что сделать» — модель `cheap` по фактам, при ошибке — шаблон.
Флаг фичи: `enabledByDefault: true`; выключение — `FEATURES_OFF=report-shift`.
Точки расширения: `reports` (`shift.summary`), маршруты `GET /api/m/report-shift/`, `POST /api/m/report-shift/run`, `GET /api/m/report-shift/export?format=csv` (право `reports`), `drilldown` → фильтр заявок смены.
Данные: заявки и события `ticket.status.changed` из `KernelStore`; смена — календарный день по часам ядра, своих таблиц нет.
Момент демо: утренний разбор — что закрыто, где просрочка и какие заявки ждут диспетчера.

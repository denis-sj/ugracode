# Модуль `reports-hub`

Что делает: страница `/reports` — хаб отчётов О1–О7 для руководителя; у каждого отчёта вопрос, период, кнопка «Сформировать», компактный результат («что это значит / что сделать»), таблица до 10 строк и выгрузка CSV.
Серверных маршрутов не добавляет: вызывает существующие `POST /api/m/report-{shift,hotspots,sla,workload,ai-effect,kb-gaps,emergency}/run` и `GET …/export?format=csv`.
Точки расширения: `web/format.ts` — `REPORTS`, разбор ответов и форматирование; `web/ReportsPage.tsx` — карточки и состояния; `web/reports.css` — стили на токенах `@ugra/ui`.
Флаг фичи: нет своего серверного модуля; страница видна ролям `manager` и `admin`, настройка — `nav` в `web/index.ts`.
Ограничения: О8 «Прогноз нагрузки» не подключён (серверного модуля нет); незнакомый формат ответа показывается JSON в `<details>`, а не падает.

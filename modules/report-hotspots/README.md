# Модуль `report-hotspots`

Что делает: отчёт О2 «Горячие точки оборудования» — топ-10 техники и кабинетов по повторным заявкам, доля, среднее время решения и тренд к прошлому периоду; вывод «что это значит / что сделать» готовит модель `cheap` только по фактам, при ошибке — шаблон.
Флаг фичи: `enabledByDefault: true`; выключение — `FEATURES_OFF=report-hotspots`.
Точки расширения: `reports` (`hotspots.equipment`), маршруты `GET /api/m/report-hotspots/`, `POST /api/m/report-hotspots/run`, `GET /api/m/report-hotspots/export?format=csv` (право `reports`), `drilldown` → фильтр заявок.
Данные: читает заявки, их события и поля через `KernelStore`; ничего не пишет, своих таблиц нет.
Момент демо: «принтер в каб. 312 — 7 заявок за месяц, дешевле заменить» — открыть точку и показать заявки.

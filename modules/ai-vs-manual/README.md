# Модуль `ai-vs-manual`

Что делает: замер К4 «с ИИ / без ИИ» — пустая форма вручную из того же реестра полей и карточка ИИ, счётчик действий (`useActionCounter`) и таймер от старта до «Готово».
Флаг фичи: `enabledByDefault: true`; выключение — `FEATURES_OFF=ai-vs-manual`.
Точки расширения: страница `/measure` для ролей `dispatcher` и `admin`; серверной части нет — сессии замера лежат в `localStorage` (❓ таблица модуля, когда замеры понадобятся отчёту).
Момент демо: финал защиты — «47 против 6 действий, 3 мин 34 с против 38 с»; `?demo=1` показывает готовые цифры с пометкой «демо-данные», кнопка «Экспорт JSON» отдаёт файл для слайда.
